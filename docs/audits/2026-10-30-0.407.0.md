## Explication technique

**Sécurité**
- Route en lecture seule, derrière `gestionnaireAuth.middlewareAuth` (app.js:349) comme le reste du routeur ; `q` borné à 300 caractères, transformé en mots `[a-z0-9]{3,}` par `motsDe` : aucune injection possible (pas de SQL, pas de regex construite depuis l'entrée — `includes`/`split` sur chaînes). Express 5 (analyseur de requête « simple ») : `q` tableau → `String()` sans effet nuisible.
- GET : pas de CSRF pertinent (rien n'est écrit). Poste de CLAIRE : `GET /authentic-claire/wiki` n'est pas dans `INTERDITS_LECTURE` (server/src/posteClaire.js:51) → permis, ce qui est voulu (lecture d'une documentation publique, aucune donnée de client).
- XSS : le résultat est rendu à l'agent en JSON, jamais injecté dans le DOM.
- Codes [NOM…] : `entreeOutilPourPoste` → `retablirValeur` rétablit les codes dans `question` avant le poste (consulter_wiki est dans OUTILS_SANS_STRICT → `sansCodesInconnus`), donc un nom de client peut partir dans l'URL vers le serveur du bureau. Aucun journal d'URL côté serveur (`originalUrl`/`req.url` non journalisés dans app.js, journalTechnique.js, securiteHote.js) ; la question ne sort pas du réseau et n'est pas renvoyée dans les passages. Sans effet.
- Ce qui part vers l'IA : les passages (titre, texte) passent par `masquerValeurLegere` quand l'anonymisation est active (mots des fiches, emails, téléphones, IBAN codés), en clair sinon — comme les textes de droit. Contenu de `server/src/data/wiki-authentic.json` contrôlé : 317 passages, aucun nom de personne réelle après une civilité, aucune personne « Prénom NOM » ; seuls « MARTIN » (exemple de recherche tiré de la doc de Fichorga), le gabarit « Prénom NOM », et des coordonnées publiques de prestataires. Aucune donnée de client dans le dépôt.

**Qualité et architecture**
- DRY : réutilise `chercherWiki` déjà employé par le pilote (authenticPilote.js:317) ; exécutant client court, erreurs rattrapées (`r.ok`, JSON illisible, réseau) et rendues en `{ erreur }`, message « rien de proche » qui guide l'IA.
- Outil ajouté partout où il faut : `OUTILS_AGENT`, `OUTILS_SANS_STRICT`, libellé de progression (client/61), aiguillage `executerOutilAgent`, consigne du prompt. Convention « toute fonction faisable par l'agent » respectée ; pas de carte « Autoriser » (lecture).
- Version 0.407.0 en tête de `HISTORIQUE_VERSIONS`, nouveauté (MINEUR + 1) cohérente.

**Performance**
- JSON de 325 Ko chargé une fois au `require` (déjà chargé par le pilote) ; recherche linéaire sur 317 passages, ≤ 4 passages de 2 200 caractères rendus (≈ 9 Ko par appel) : sans risque pour la boucle d'événements ni pour la limite de jetons.

**Conformité**
- Route synchrone pure (pas d'accès disque) : `routeAsync` inutile, une exception synchrone est rattrapée par Express.
- wiki.js est en `// @ts-check` ; rien à typer de plus.
