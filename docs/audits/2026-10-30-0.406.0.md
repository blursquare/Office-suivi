## Points vérifiés sans défaut

- **XSS** : tout texte rendu passe par `escapeHtml` / `escapeAttr` ; identifiants dans les `onclick` par `escapeOnclickArg` (dossier et lignes) ; `notes` (noms de fichiers du NAS) échappées ; aperçu par `htmlCourrierFidele`, qui échappe chaque run (`htmlRunsCourrier` → `escapeHtml`), le destinataire et les cellules du tableau saisis par l'utilisateur compris. Aucun `innerHTML` d'une valeur brute.
- **Masquage vers l'IA** : `decompteVendeurAgent` ne rend ni le destinataire, ni la référence, ni le nom d'un fichier (`« … »` remplacé par `(fichier)`) ; libellés saisis à la main et sources passent par le masquage du serveur comme tout résultat d'outil ; test « rien de nominatif ne part » ajouté (`server/test/assistant-agent.test.js`, nom tapé dans un libellé). Montants et dates en clair : conforme au choix de l'étude.
- **Règle n° 4** : `email: true` → carte « Autoriser », puis `livrerEmailDossier` (fenêtre d'email, rien ne part sans « Envoyer ») ; l'annulation de la fenêtre est rendue telle (`fenêtre fermée sans envoi`). Le prompt de l'agent ne lui fait pas dire « envoyé » sans statut.
- **NAS** : aucune nouvelle route ; lecture par `/api/nas/fichier` existant (confiné par `resoudreCheminNas`, asynchrone). Aucune écriture sur le NAS.
- **Secrets** : aucun manipulé. **Données réelles** : tests aux noms et montants inventés ; CLAUDE.md rappelle que le modèle reçu ne doit jamais être commité.
- **Convention « tout geste faisable par CLAIRE »** : outil `decompte_vendeur` + exécutant poste + ligne du prompt + test : respectée. Hors `strict` (dans `OUTILS_SANS_STRICT`), champs tous obligatoires, `additionalProperties: false`.
- **Intégration** : onglet déclaré dans `definirOnglet`, `NOMS_ECRANS`, `OUTILS_ONGLETS_TRAVAIL`, `ICONES_ONGLETS_OUTILS`, `ECRANS_CLAIRE_FLOTTANTE`, manifeste, `<script>` et fumée. Rangé dans le tiroir « Vente » par ordre alphabétique (entre « Contrôle de l'urbanisme » et « Prorata »). Points terrain présents (mais en double, H1).
- **Concurrence** : jeton `dvEtat.jeton` + `encore()` empêchent une lecture du NAS d'écrire sur un autre dossier choisi entre-temps ; `dvEtat.envoi` empêche un double email.

### M1 — ne pas écraser un décompte en cours sans accord

```js
async function decompteVendeurAgent(e) {
  // … recherche du dossier inchangée …
  const enCours = dvEtat.dossierId && dvEtat.lignes.some(x => x.modifiee);
  if ((dvEtat.dossierId !== d.id && enCours) || (e.relire && enCours)) {
    const ok = await demanderAutorisationAgent(dvEtat.dossierId !== d.id

    if (!ok) return { erreur: 'refusé par l’utilisateur : le décompte en cours est gardé' };

  // … suite inchangée …
}
```
