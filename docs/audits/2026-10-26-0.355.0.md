# Relecture et audit — CLAIRE 0.355.0 (26/10/2026)

Périmètre : « Répondre » d'une notification du relais (relais 2.2, `server/src/relaisPoste.js` : action `repondre`,
`scriptFenetreReponse`, `adresseReponse`) ouvrant la page autonome `repondre.html` ; canaux relus toutes les 5 s quand la fenêtre
n'est pas regardée et que le relais notifie (`client/114-canaux.js`). Non vérifiable ici : Windows (placement par UI Automation,
fermeture de la fenêtre `--app`), Chrome déjà lancé.

## Verdict

**Correct avec réserves.** Aucun point « Haut ».

| # | Gravité | Problème | Suite donnée |
|---|---|---|---|
| M1 | Moyen | `--window-size`/`--window-position` ignorés par un Chrome déjà lancé, appliqués à toutes ses fenêtres sinon | **Corrigé** : fenêtre retrouvée par son titre et placée par UI Automation (TransformPattern), secours `resizeTo`/`moveTo` dans la page |
| M2 | Moyen | HTML d'un message de CLAIRE posé par `innerHTML` dans une div (images chargées, `onerror`) | **Corrigé** : `DOMParser` (document inerte), texte seul |
| M3 | Moyen | Fenêtre réduite plus de 5 min : Chrome ne réveille les minuteries qu'une fois par minute, le relevé à 5 s n'y joue plus | **Non corrigé**, dit à l'étude ; correction durable : carte écrite par le serveur au dépôt du message (comme `carteReaction`) |
| B1 | Bas | `titre` d'un lien forgé affiché comme lieu de la réponse | **Corrigé** : lieu tiré du canal, titre seulement pour un dossier |
| B2 | Bas | CLAIRE ne répond pas depuis la petite fenêtre | **Dit** dans la fenêtre quand le message cite CLAIRE ou vient d'elle |
| B3 | Bas | Session refusée : message trompeur | **Corrigé** (« Ouvrez CLAIRE pour vous reconnecter ») |
| B4 | Bas | Message de départ du fil retiré : envoi refusé sans explication | **Corrigé** |
| B5 | Bas | Envoyer actif avant le chargement | **Corrigé** (désactivé jusqu'au chargement) |
| B6 | Bas | Libellé du dossier dans la ligne de commande de Chrome | Accepté (déjà dans l'historique du profil Claire) |
| B7 | Bas | Collaborateur lu dans le stockage du navigateur | Accepté (le serveur ne vérifie pas qui parle) |
| B8 | Bas | Plusieurs écrans d'échelles différentes | À observer (point `relais-fenetre-reponse`) |
| B9 | Bas | Point `relais-node-boutons` citait « Répondre » | **Corrigé** |
| B10 | Bas | Page sans politique de contenu | **Corrigé** : CSP en `<meta>`, script par empreinte (le test de fumée échoue si l'empreinte ne suit pas) |

Aussi : avertissement ESLint (`fs` inutilisé dans `relaisWord.js`, reste de 0.354.0) retiré.
