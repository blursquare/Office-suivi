# Audit 0.231.0 — plan aérien IGN et numéros de parcelles sur les photos à comparer (15/10/2026)

Second agent, lecture seule, cadre de l'étude (sécurité, qualité, performance, conformité) sur `planAerien.js`, `routes/planAerien.js`,
`urbanisme.js`, `client/68-sites-claire.js`. **Verdict : prêt avec réserves mineures — aucun point Haut.**

| Niveau | Point | Suite |
|---|---|---|
| Moyen | Balayage synchrone : tous les sommets de chaque zone à chaque ligne (4 zones de 100 000 sommets = 2,8 s figées) | Corrigé : seules les arêtes qui touchent la bande de la parcelle sont gardées (`aretesDansBande`) ; test avec une zone de 150 000 sommets < 1,5 s |
| Moyen | Contours de zone tracés sans élagage hors cadre, clé de dédoublonnage par `JSON.stringify` | Corrigé : segments hors cadre ignorés, clé légère |
| Moyen | Zones complètes dans le cache partagé (500 entrées), clé pouvant se heurter | Corrigé : cache à part (30 entrées, 10 min), clé = SHA-1 de la géométrie |
| Moyen | Toute erreur rendue « IGN injoignable » et notée en échec au point terrain | Corrigé : 502 et point terrain seulement pour une vraie panne réseau/IGN, sinon 500 journalisé |
| Bas | `Math.min(...)` sur un grand anneau fait déborder la pile | Corrigé (`bornes`) |
| Bas | Durée de vie de 2 h non appliquée à la lecture et au rangement | Corrigé |
| Bas | Un plan sans dossier rangeable dans n'importe quel dossier | Corrigé : refusé |
| Bas | Ancien plan affiché après changement de commune/parcelles | Corrigé : effacé |
| Bas | ~8 appels séquentiels par parcelle | Atténué : trois parcelles à la fois ; appels doublés de `zone-urba` laissés (mis en cache) |
| Bas | Étiquettes de zone presque jamais posées | Corrigé : anneau coupé au cadre avant de chercher le centre |
| Bas | Mètres par degré de latitude (110 574 → 111 18x) | Corrigé (formules WGS84) |
| Bas | Apostrophe dans le nom de fichier | Corrigé |
| Bas | Zones de même libellé non fusionnées | Corrigé : fusion libellé + type + libellé long |
| Bas | URL blob révoquée après 5 min | Allongée à 1 h |

Non vérifié : très grand PLUi réel, rendu papier, accès à `data.geopf.fr` depuis le serveur du bureau.
