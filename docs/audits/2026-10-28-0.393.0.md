## Verdict global

**Correct avec réserves.** Aucun point Haut. La version renforce la garde d'Authentic (écriture CJN/Comedec désormais contrôlée par
`o.ecriture` au lieu de `true` en dur, un seul bloc de création ouvert avant « Valider », chevrons refusés marqués et sautés, menus d'actions

aucune requête SQL ajoutée ; aucun secret touché ; aucune donnée réelle dans les tests (noms inventés) ; regex nouvelles sans quantificateurs
imbriqués (pas de ReDoS) ; l'outil `lectures_documents` passe par le masquage FORT (`masquerValeur`, il n'est pas dans la liste du masquage
léger) ; scripts injectés par CDP : seules des chaînes passées par `JSON.stringify` (url, pjId, regex).

## Explications techniques

**M1.** Le tuyau CDP réunit les morceaux puis fait `Buffer.concat` → `toString('utf8')` → `JSON.parse` → `Buffer.from(b64, 'base64')` :
quatre copies vivantes en même temps pour un seul PDF, et un `JSON.parse` de 80 Mo bloque la boucle d'événements (requêtes des postes, relais,
3CX) plusieurs centaines de millisecondes. Le délai de 45 s de `envoyer` s'applique à l'ensemble fetch + conversion + transfert ; en cas de
dépassement, le PDF est quand même transféré et analysé puis jeté (coût payé pour rien), et l'étude voit « PDF illisible ». Côté onglet, la
chaîne binaire de 60 M caractères puis le `btoa` de 80 Mo restent en mémoire du Chrome sans écran jusqu'au ramasse-miettes. La conservation de
5 min (`DUREE_PIECE_MS`) et une tâche à la fois limitent la rétention, pas le pic.

**M2.** Le modèle rend `sd.pieces` sans indicateur de complétude ; l'étude se fie à « pas d'EHF » ou « acte de naissance absent » pour une
décision (relance du SPF, signature). Une liste incomplète doit être dite comme telle, comme pour les suivis.

**M3.** Le motif ne contient aucune ancre structurelle : il s'applique à `a, span, div, h2…` de toute la page. Les vrais répertoires de la GED
sont des nœuds d'un arbre PrimeFaces (`.ui-tree`) ; les autres blocs « (N) » de la page du sous-dossier passent avant eux dans l'ordre du DOM.

**M4.** `paires[0]` est toujours le même élément tant qu'il reste masqué : aucun autre chevron n'est jamais essayé et `reste` remonte à 0.

## Plan de remédiation (points Moyens)

**M1 — lecture par morceaux, délai explicite, taille contrôlée avant téléchargement :**

```js
// authenticClaire.js
const MORCEAU_PDF = 8 * 1024 * 1024;
const scriptChargerPdf = (url) => `fetch(${JSON.stringify(url)}, { credentials: 'include' }).then(async (r) => {
  if (!r.ok) return null;
  const n = Number(r.headers.get('content-length') || 0);
  if (n > 60 * 1024 * 1024) return null;            // refusé avant tout téléchargement
  const b = await r.arrayBuffer();
  if (b.byteLength > 60 * 1024 * 1024) return null;
  const u = new Uint8Array(b);
  if (String.fromCharCode(u[0], u[1], u[2], u[3]) !== '%PDF') return null;
  window.__clairePdf = u; return u.length; })`;
const scriptMorceauPdf = (debut) => `(() => { const u = window.__clairePdf; if (!u) return null;
  const m = u.subarray(${debut}, ${debut} + ${MORCEAU_PDF}); let s = '';
  for (let i = 0; i < m.length; i += 32768) s += String.fromCharCode.apply(null, m.subarray(i, i + 32768));
  return btoa(s); })()`;

// dans lirePiecePdf
const taille = await s.cdp.envoyer('Runtime.evaluate', { expression: scriptChargerPdf(url), returnByValue: true, awaitPromise: true },
  s.ongletActif().session, 180000).then((r) => r.result && r.result.value);
if (!taille) throw new Error('PDF illisible ou de plus de 60 Mo');
const parts = [];
try {
  for (let debut = 0; debut < taille; debut += MORCEAU_PDF) {
    const b64 = await g.ev(scriptMorceauPdf(debut));
    if (!b64) throw new Error('PDF illisible');
    parts.push(Buffer.from(String(b64), 'base64'));
  }
} finally { await g.ev('delete window.__clairePdf').catch(() => {}); }
return { nom: pos.nom, pdf: Buffer.concat(parts, taille) };
```
(Pic serveur ramené à ~2 × 11 Mo par morceau + le Buffer final ; chaque `JSON.parse` court ; délai adapté au téléchargement seul.)

## Points Bas — correctifs proposés

  compilées en constantes.
