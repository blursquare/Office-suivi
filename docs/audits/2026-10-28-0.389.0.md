# Audit 0.389.0 — comptabilité d'un dossier lue dans Authentic

Audit indépendant (second agent). Verdict : **publiable, aucun point Haut** ; risques de fonctionnement au premier essai corrigés avant l'envoi.

| Gravité | Constat | Remédiation | État |
|---|---|---|---|
| Moyen | Après le clic sur « Comptabilité », `estCeDossier` exigeait « Comparants (N) », peut-être absent sur cet onglet : refus à tort. | Seule la référence en tête est contrôlée (dossier vérifié avant le clic) ; messages distincts. | Corrigé |
| Moyen | Tableau défilant de PrimeFaces (en-tête et corps en deux tables) : la table d'en-tête vide était choisie. | Corps qui a des lignes, en-tête repris de la table qui précède ; test. | Corrigé |
| Moyen | Totaux présentés comme ceux du compte alors qu'ils portent sur les opérations listées. | Renommés « des opérations listées » (fiche et agent). | Corrigé |
| Bas | Un seul « Solde du compte » lu. | `nombreComptes` dit à l'agent. | Corrigé |
| Bas | Signe « − » typographique, date lue comme montant. | Acceptés / refusée ; tests. | Corrigé |
| Bas | « Générer en PDF », « Ajouter un compte », « Détacher de l'acte » seulement écartés par la liste fermée. | Ajoutés au second filet `RE_INTERDIT`. | Corrigé |
| Bas | `t.resultat` inutile ; échec non noté au point terrain ; message dans le canal à chaque lecture ; `relire` « false » en texte ; bloc caché sans instantané. | Retiré ; noté ; silencieux ; `=== true` ; bloc rendu depuis le panneau Authentic. | Corrigé |
| Bas | Ordinateur virtuel de CLAIRE : route hors `PERMIS_ECRITURE` (comme `/authentic-claire/lire`). | Laissé ainsi : refus clair du serveur. | Accepté |

Vérifié sans défaut : garde (libellé fermé, aucun clic d'écriture), forme de la capture (`releve.js`), écriture sur la fiche relue juste avant, fusion à trois voies, verrou, masquage des libellés (test), échappement, échelle de style.

Non vérifié : la vraie page d'Authentic (en-tête et comparants sur cet onglet, tableau défilant, pagination, format des montants) — point `authentic-comptabilite`.
