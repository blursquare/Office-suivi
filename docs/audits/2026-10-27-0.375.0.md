# Audit 0.375.0 — œil « Vu » dans les conversations privées

Relecture et audit en lecture seule par un second agent (cadre de l'étude du 13/10), sur le diff de la version avant envoi.

## Verdict

**Correct avec réserves** — aucun point « Haut ».

Points tenus : `lusPar` rendu seulement pour un canal privé et à l'un de ses membres (contrôlé par `canalDe` puis par `lusParAutresMembres`), jamais pour un canal partagé ni un non-membre ; noms de la liste fermée des collaborateurs, échappés ; horloges comparées toutes deux posées par le serveur.

## Tableau priorisé

| # | Criticité | Endroit | Problème |
|---|---|---|---|
| M1 | Moyen | server/src/canaux/canaux.js, client/115 | « Vu par Julie à HH:MM » donnait la DERNIÈRE lecture, qui avance toutes les ~20 s tant que la conversation reste ouverte, pas l'heure où le message a été vu. |
| M2 | Moyen | server/src/routes/canaux.js | La signature contenait les heures brutes : rechargement et redessin complets du canal toutes les ~24 s des deux côtés (sélection perdue, menus refermés). |

| B2 | Bas | tests | Pas de test de la route GET ni du rendu. |

## Suite donnée

- **M1, M2 — corrigés** : `marquerLu` retient, pour un canal privé, la PREMIÈRE lecture après le dernier message (clé `canaux-vus`, `{ apres, le }`) ; `lusParAutresMembres` rend cette heure figée (sinon la dernière lecture, restée avant le message) ; la signature ne change plus qu'une fois, quand le message est vu. Tests : heure figée malgré une relecture, route GET (privé à un membre, `{}` sur un canal partagé, `inchange` après une relecture).
- **B1** — accepté (comme Teams) et dit dans l'historique ; **B2** — test de route ajouté ; **B3** — négligeable.
