# Audit — versions 0.364.0 à 0.370.2 (27/10/2026)

Audit fait en lecture seule sur le diff de relecture (profil de CLAIRE, moment de la journée, présence dans Authentic, vue d'ensemble d'un
dossier, report d'une tâche, ordinateur virtuel de CLAIRE, travaux en arrière-plan, messages de CLAIRE à la place de Teams, ajout au
Répertoire par l'agent, fil de conversation, mémoire des autres conversations). Cadre de l'étude du 13/10. Rien de nominatif ici.

Vérifications faites en plus de la lecture : `routeInterditePosteClaire` appelée sur des chemins réels, et une mini-application Express 5
(celle du serveur) qui montre quels chemins atteignent vraiment une route ; liste de toutes les routes d'écriture du serveur passées au filtre
du poste de CLAIRE.

## Verdict global

**Correct avec réserves — à ne pas publier en l'état** : deux points **Haut**, tous les deux sur le garde-fou de l'ordinateur virtuel de
CLAIRE. Le cadrage de l'étude, « jamais d'accès aux réglages ni aux boutons d'envoi, refusés par le SERVEUR », n'est pas tenu par le
code : le filtre est une liste noire, qu'on contourne en changeant la casse ou en ajoutant une barre finale, et qui oublie des réglages et
des écritures vers Exchange. Pour en profiter, il faut qu'un code s'exécute dans la page du poste de CLAIRE (les `fetch` du poste ont des
adresses fixes). Mais cette page lit des documents et des réponses d'IA, et le garde-fou existe justement pour le cas où ce qu'elle
exécute ne serait plus sûr. Le reste est solide :
- masquage de la mémoire et de l'en-tête Authentic ;
- cookie secret bien traité ;
- échappement de l'affichage ;
- accès disque asynchrone ;
- aucune donnée réelle.

### H1 + H2 — chemin normalisé et liste BLANCHE des écritures du poste de CLAIRE

```js
// server/src/posteClaire.js
/** Pure : le chemin tel qu'Express le route (sans /api, minuscules, sans barres doubles ni finale) ; null si illisible. */
function cheminNormalise(chemin) {
  let c = String(chemin || '').split('?')[0].split('#')[0];
  try { c = decodeURIComponent(c); } catch (_) { return null; }
  if (/[\\\0]|\/\.\.?(\/|$)/.test(c)) return null;
  c = c.toLowerCase().replace(/\/{2,}/g, '/').replace(/\/+$/, '');
  return c.replace(/^\/api(?=\/|$)/, '') || '/';
}

// Lectures refusées (liste noire, sur le chemin normalisé).
const INTERDITS_LECTURE = [/^\/reglages(\/|$)/, /\/reglages(\/|$)/, /^\/comptes-collaborateurs(\/|$)/, /^\/mise-a-jour(\/|$)/,
  /^\/sauvegarde(\/|$)/, /^\/yousign(\/|$)/, /^\/relais-word(\/|$)/, /^\/claire-messages(\/|$)/, /^\/emails-matin(\/|$)/];

// Écritures PERMISES (liste blanche : toute nouvelle route est refusée tant qu'on ne l'y ajoute pas).
const PERMIS_ECRITURE = [
  ['POST', /^\/assistant\/(agent|comprendre|converser|correspondance-acte)$/],
  ['POST', /^\/poste-claire\/demande$/],
  ['PUT', /^\/dossiers\/[^/]+$/],                    // gestes validés par Bastien (sauvegarder)
  ['POST', /^\/rappels-perso$/],
  ['POST', /^\/repertoire$/],
  ['POST', /^\/nas\/(deposer-document|explorer\/(renommer|deplacer))$/],
  ['POST', /^\/verifications-terrain(\/|$)/], ['POST', /^\/journal-technique(\/|$)/]
  // … à compléter d'après les 403 relevés par tests/fumee/poste-claire.mjs, jamais par préfixe large
];

function routeInterditePosteClaire(methode, chemin) {
  const c = cheminNormalise(chemin);
  if (c === null) return true;
  const m = String(methode || 'GET').toUpperCase();
  if (m === 'GET' || m === 'HEAD') return INTERDITS_LECTURE.some((re) => re.test(c));
  return !PERMIS_ECRITURE.some(([mm, re]) => mm === m && re.test(c));
}
```
