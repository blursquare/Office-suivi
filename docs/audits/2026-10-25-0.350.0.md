## Points relevés

| Gravité | Point | État |

| Moyen | Réponse depuis la carte : canal libre ou dossier inventé acceptés (entrée créée en base) ; réponse d'un fil posée à la racine | Corrigé : mêmes contrôles d'existence que la route ; la carte porte le fil, la réponse y est rangée |
| Bas | Texte d'une personne amputé de ce qui est entre « < » et « > » ; entités HTML d'une réponse de CLAIRE affichées brutes | Corrigé |
| Bas | Erreur de lecture des cartes = route en 500 | Corrigé : journal sans texte de message, pastille servie |
| Bas | « & » pris pour un raccourci clavier dans la carte | Corrigé (`UseMnemonic = false`) |
| Bas | Carte perdue quand un canal monte pendant qu'un autre est lu (total inchangé) | Corrigé |
| Bas | Carte qui montrait la carte de proposition d'un autre comme dernier message | Corrigé (cartes de proposition écartées) |
| Bas | « Ouvrir » d'une carte de rubrique menait à « À traiter » | Corrigé : montre CLAIRE seulement |
| Bas | Entrée puis clic : réponse en double ; champ bloqué après une erreur (relecture) | Corrigé : un seul envoi à la fois, champ rendu après une erreur |
