## Explication technique

- **H1** : la règle n° 4 (aucun email au client sans « Envoyer ») n'est levée au niveau 2 que parce que l'humain clique lui-même
  sur la carte de proposition. Si l'agent clique ce bouton, plus aucun humain n'intervient : l'email part. Le libellé
  « Ouvrir le brouillon » est fixe (`TYPES_PROPOSITION.email.bouton`), quel que soit le niveau.
- **H2** : « jamais valider un téléchargement » est une exclusion explicite. Un nom de fichier n'est pas un verbe : le
  classement ne peut pas deviner qu'un clic sur « devis.xls » télécharge. « Excel » n'est pas dans `RE_BOUTON_JAMAIS`
  (seuls `xlsx`, `csv`, `pdf`, `word`, `docx` y sont).
- **M1** : « Autoriser pour toute cette demande » a été pensé pour les gestes de l'agent ; appliqué à un bouton qui est
  lui-même une décision (Autoriser / Refuser une proposition), il transforme une autorisation générale en décision d'une
  autre demande, y compris une validation de l'ordinateur virtuel de CLAIRE.
- **M2** : l'outil devait garder « écrire après la carte ». Les écritures ci-dessus passent sans carte et, pour « Coller »,
  touchent l'agenda partagé de l'office (une écriture que tous les autres outils de l'agent font après la carte).

## Plan de remédiation

1. **Classer aussi par la fonction appelée et par la place** (H1, H2, M1, B3) — dans `classementBoutonAgent`, ajouter un
   4e argument `action` = nom de la fonction de l'attribut `onclick` :

```js
var RE_ACTION_JAMAIS = /^(telecharg|imprim|exporter|envoyer|preparerSignatureRib|ouvrirPieceJointeEmail|ouvrirFichierExplorateurNas|installer|autoriserProposition|refuserProposition|dejaFaitProposition|terminerProposition)/i;
var RE_ACTION_CARTE = /^(coller|ecarter|retirerExclusion|ajouter|marquer|poser|deposer|reagir|basculer|enregistrer|confier)/i;
function actionBoutonAgent(el) {
  return (/^\s*(?:event\.stopPropagation\(\);\s*)?([A-Za-z_$][\w$]*)\s*\(/.exec(el.getAttribute('onclick') || '') || [])[1] || '';
}
function classementBoutonAgent(libelle, titre, place, action) {
  const t = `${libelle || ''} ${titre || ''}`;
  if (place === 'reglages' || place === 'telechargement' || place === 'proposition') return 'jamais';
  if (RE_ACTION_JAMAIS.test(action || '') || RE_BOUTON_JAMAIS.test(t) || /\bexcel\b/i.test(t)) return 'jamais';
  if (RE_BOUTON_STRICT.test(t)) return 'strict';
  if (RE_ACTION_CARTE.test(action || '') || RE_BOUTON_CARTE.test(t) || /^\s*\+/.test(libelle || '') || /[ée]carter|coller|laisser/i.test(t)) return 'carte';
  return 'libre';
}
// placeBoutonAgent : une carte de proposition (« Autoriser », « Ouvrir le brouillon », « Refuser ») n'est jamais pour l'agent
if (el.closest && el.closest('.proposition-carte, .pc-actions')) return 'proposition';
```
