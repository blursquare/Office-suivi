# Audit 0.378.0 — CLAIRE dans Authentic, étape 4 : aperçus des formalités

Audit sécurité / qualité / performance / conformité par un second agent (cadre de l'étude du 13/10), 27/10/2026.

**Verdict de l'audit : pas prêt (deux points Haut) — corrigés avant tout envoi**, puis contrôlés par la fumée du faux Authentic (corbeille
« Supprimer l'aperçu » sur la ligne survolée, jamais cliquée).

| Gravité | Où | Constat | Suite donnée |
|---|---|---|---|
| Haut | `authenticClaire.js` (`scriptIconeApercu`, `lireApercusFormalites`) | La garde ne voyait pas l'icône cliquée (titre/aria/classe de l'icône absents, repli « aperçu » sans libellé, classes de corbeille non vues) : `<i class="pi pi-trash" title="Supprimer l'aperçu">` passait ; « delete_forever » non reconnu. | **Corrigé** : libellé = ce qui est SOUS le pointeur (titre, aria, alt, classe de l'élément et de son bouton, « supprimer » si corbeille) ; plus de repli ; corbeilles écartées d'avance ; garde : le geste `apercu` exige un libellé qui dit l'aperçu ; `delete_\w*`, `trash`, `poubelle` dans la liste noire. |
| Haut | idem | Pas d'`elementFromPoint` ; un tiroir resté ouvert faisait cliquer sous lui (sa corbeille). | **Corrigé** : vérifié sous le pointeur ; un tiroir qui ne se referme pas arrête la lecture des aperçus. |
| Moyen | `scriptIconeApercu` | `voir` prenait « pouvoir » ; le titre de la ligne pouvait être pris. | **Corrigé** : `voir` en mot entier ; jamais un élément qui porte du texte (> 3 caractères). |
| Moyen | `lireApercusFormalites` | Positions prises avant le défilement. | **Corrigé** : la ligne est amenée à l'écran, puis survolée à sa position recalculée. |
| Moyen | `SCRIPT_TIROIR_OUVERT`, `releve.js` | `.ui-sidebar-active` trop large ; « Fermer » cherché dans toute la page. | **Corrigé** : tiroir `previewFormalite` / `sideView` seul ; « Fermer » dans le tiroir, vérifié sous le pointeur. |
| Moyen | `lireDossier` | La page gardée était celle d'un tiroir ouvert. | **Corrigé** : page relevée de nouveau tiroirs fermés ; le texte du tiroir est retiré du texte de la page dans le relevé. |
| Bas | `SCRIPT_LIGNES_FORMALITES` | `T@` jamais pris (`\b`). | **Corrigé.** |
| Bas | `rangerApercuAT` | Libellé vide prenant tous les aperçus. | **Corrigé** : libellé vide ignoré, le plus long d'abord. |
| Bas | `CHAMPS_APERCU_AT` | `reference` lue sans usage. | **Retirée.** |
| Bas | `pagesAuthentic.js` | Aperçus anciens gardés jusqu'à la limite de 40 pages. | Acceptable. |
