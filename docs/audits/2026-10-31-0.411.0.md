## Explications

**H1 — libellé de l'agence vers l'IA.** `piecesDecoupageCompromis` : `const label = ty.label || (seg.libelle ? seg.libelle.charAt(0).toUpperCase() + … : …)`,
puis `nom: nomPieceDecoupage(label)`. Pour une annexe que CLAIRE ne reconnaît pas, le nom est donc le libellé saisi dans le logiciel de l'agence,
qui porte souvent un nom de client (« attestation dupont paul »). `decouperCompromisAgent` rend `titre_piece: p.nom`. Le serveur masque le résultat
comme tout résultat d'outil (`masquerValeur`, vérifié l. 1112-1118 d'`assistantAgent.js` : `decouper_compromis` n'est pas dans le masquage léger),
mais ce masquage repose sur les fiches, les capitales et les majuscules : la mise en majuscule de la seule première lettre laisse un nom de famille
écrit en minuscules en clair. Le test serveur (`assistant-agent.test.js`) ne couvre qu'un nom en capitales. Le nom du fichier déposé (`seg.fichier`)
n'est, lui, jamais repris (vérifié).

**M1 — mémoire du serveur.** `express.json({ limit: '40mb' })` met tout le corps en mémoire, l'analyse sur le fil principal, puis la route
recopie en `Buffer`. Node étant mono-thread, une analyse de 40 Mo fige les autres requêtes quelques dizaines à centaines de ms (mesure non faite ici,
estimation). Le poste range les pièces une par une, ce qui borne la charge d'UN poste, pas celle de plusieurs.

**M2 — mémoire du poste.** pdf.js garde le document dans son worker tant que `destroy()` n'est pas appelé ; le nettoyage par le ramasse-miettes
n'est pas garanti côté worker. Les autres lecteurs de CLAIRE appellent `destroy()`.

**M3 — PDF chiffré.** Avec `ignoreEncryption`, pdf-lib copie les flux chiffrés tels quels dans un nouveau document non chiffré : les pages sont
blanches ou illisibles. Les deux compromis réels décrits dans l'historique sont signés (SignServer), pas forcément chiffrés : supposition, non vérifiée
sur un vrai fichier.

## Plan de remédiation

H1 — `client/152-decoupage-compromis.js`, dans `decouperCompromisAgent` :

```js
// Jamais le libellé ni le nom de fichier de l'agence (noms de clients), ni un nom tapé à la main : le libellé de CLAIRE seulement.
const titreSur = (p) => p.sorte === 'compromis' || p.sorte === 'diagnostics' ? nomPieceDecoupage('', p.sorte)
  : p.sorte === 'diagnostic' ? (diagnosticParCle(p.diagnostic) || diagnosticParCle('synthese')).label
    : p.reconnu ? p.label : `Annexe n°${p.numero} (non reconnue)`;
// …
pieces: dcEtat.pieces.map(p => ({ id: p.id, sorte: p.sorte, titre_piece: titreSur(p), nom_modifie: !!p.modifiee, pages: p.saisie, … })),
```

`p.reconnu` vaut `!!ty.label` pour une annexe ; `p.label` est alors un libellé de CLAIRE (TYPES_SCAN ou `ANNEXES_COMPROMIS`). Ajouter dans
`tests/decoupage-compromis.test.js` un compromis dont une page de séparation porte « attestation dupont paul » et vérifier que `dupont` n'apparaît
pas dans le résultat de `decouperCompromisAgent`.
